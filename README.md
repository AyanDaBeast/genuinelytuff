# genuinelytuff

A small collection of bookmarklets kept in separate files.

## How to use

- Open `index.html` in the repo.
- Drag any bookmarklet link to your browser bookmarks bar.
- Click it on the page you want to use it on.

## Structure

- `index.html` lists the bookmarklets.
- `bookmarklets/` stores each bookmarklet in its own file.
- `gkt.html` contains the Gimkit helper page.
